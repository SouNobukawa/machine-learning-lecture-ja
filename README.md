# 機械学習の数学

大学の機械学習講義テキスト。内積・行列から最小二乗法、正則化、ベイズ、SVM、ニューラルネットワークまで、**数学を省略せずに積み上げる**全13回構成です。

## すぐ読む

**[text.pdf](text.pdf)** — 講義テキスト本体（76ページ、第4回まで執筆済み）

ビルド不要で読めます。LaTeX ソースは [`text.tex`](text.tex) です。

## 特徴

- **式変形を飛ばさない。** 「明らかに」で済ませず、どの性質を使ったかを各行に明記します
- **幾何学的な意味を必ず添える。** 内積は長さと向きの一致度、最小二乗法は列空間への正射影、というように、式と図を対応させます
- **同じ結果を複数の道筋で導く。** 例えば正規方程式は、射影の幾何学と微分の両方から導出します
- **記法を定義してから使う。** $\arg\min$、$(x,y) \sim P$、集合の内包表記なども、初出時に読み方から説明します

## ビルド方法

`uplatex` + `dvipdfmx`（日本語 LaTeX）を使います。

```bash
uplatex text.tex && uplatex text.tex && dvipdfmx text.dvi
```

目次と相互参照を解決するため **2回** 実行してください。提出用テンプレートも同じ手順です。

```bash
uplatex report_template_03.tex && dvipdfmx report_template_03.dvi
```

### 図を作り直す

`figures/` の中身はリポジトリに含まれているので、通常は再生成不要です。変更したい場合は:

```bash
uv run --with matplotlib --with numpy python make_figures.py
```

> **注意**: 図中の日本語は macOS の Hiragino Sans を指定しています。他の環境では `make_figures.py` 冒頭の `font.family` を手元の日本語フォントに変更してください。
